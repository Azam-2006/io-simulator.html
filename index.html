I/O Operations & Interrupt-Driven Architecture
VECTORED INTERRUPT MODEL (RV32I)

Interrupt-Driven I/O.
Zero polling overhead.

Simulate hardware asynchronous interrupts: observe the CPU execute user tasks, halt on INTR, push PC to the stack, execute the Interrupt Service Routine (ISR), and execute IRET without CPU polling loops.

02 System Bus & Signal Lines
Tri-State Bus
INTR (Interrupt Request Line) LOW (0)
INTA (Interrupt Acknowledge Line) HIGH (1 - Inactive)
DATA BUS (Vector / Payload) FLOATING (High-Z)
Sequence Interrupt Handling Phases
  • 1. Normal Execution: Main Loop Program
  • 2. Asynchronous IRQ: Peripheral sets INTR line High
  • 3. CPU Acknowledge: Current instruction finishes, INTA pulsed
  • 4. Context Save: Push Program Counter (PC) & state to Stack
  • 5. Vector Branch: Load ISR address (0x0400) into PC
  • 6. Data Transfer: Read byte from I/O Device Buffer
  • 7. Return from Interrupt (IRET): Pop PC, resume Main Loop
